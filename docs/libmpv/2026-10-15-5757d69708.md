# libmpv-2.dll: build inputs

Zeiler's Windows installer ships `libmpv-2.dll` from the LGPL x86_64 build of
[zhongfly/mpv-winbuild](https://github.com/zhongfly/mpv-winbuild) release `2026-10-15-5757d69708`.
zhongfly deletes releases and tags older than about 30 build days (`prunetags.sh`), so
Zeiler keeps the archive, this record and the source of every LGPL component on its own
release, [`libmpv-2026-10-15-5757d69708`](https://github.com/malhaniah/zeiler/releases/tag/libmpv-2026-10-15-5757d69708). That release is the source offer's
"complete corresponding source" for this build.

## The binary

- Archive: `mpv-dev-lgpl-x86_64-20261015-git-5757d69708.7z`, SHA-256
  `5417be2641c31e2c5e676bb7cce90244edb43758936193c6c36dfcf5ea35eabd` (as in zhongfly's
  `sha256.txt`, mirrored unchanged). `scripts/fetch-libmpv.mjs` downloads it from the
  mirror and checks that hash.
- The DLL reports mpv `v0.41.0-1184-g5757d6970` and FFmpeg `N-127570-gaf25036ac`.

## How it was built

- Workflow run [38790360376](https://github.com/zhongfly/mpv-winbuild/actions/runs/38790360376) (`.github/workflows/mpv.yml`, workflow_dispatch,
  2026-10-15 19:00 UTC), job "Build MPV (64, true)" (id 116613101513): x86_64, LGPL
  flavour, clang. No mpv pull requests were merged in and no custom command ran.
- zhongfly/mpv-winbuild at `8a39c5134b8e16f104ee56a5d85e36a592ad9477`. Its
  `patch/0002-spirv-cross-shaderc-skip-unused-stuff.patch` and `compile-lgpl-libmpv.patch`
  are applied with `git am` on top of:
- shinchiro/mpv-winbuild-cmake at `1f8d2e76255abc48f0456d9be99b4cab9c6566e6` (master;
  the job summary reads `master...origin/master [ahead 2]`, the two patches above).
  Its `packages/*.cmake` give every library's source URL, build options and patches.
- `bash build.sh -t 64 -c clang -s true`: CMake for `x86_64-w64-mingw32` with the clang
  toolchain, then `ninja update` (every git package moved to its upstream branch head),
  then `ninja mpv`.
- Container `ghcr.io/archlinux/archlinux:base-devel` (pulled 2026-10-15).
- Compiler: clang version 23.1.2 (https://github.com/llvm/llvm-project.git
  03b58ead1a5d7caae4ab76ec69d66cfa896da372).
- Rust: rustc 1.100.0-nightly (420ed2a0c 2026-09-18), cargo 1.100.0-nightly
  (495c385d0 2026-09-16), rustup 1.29.1.
